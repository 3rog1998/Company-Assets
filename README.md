# نظام إدارة العهد — مصنع مروى للمياه الصحية

نظام ويب خفيف لإدارة عهد الشركة (تسليم وإرجاع) لمستخدمَين فقط (مسؤول العهدة + المدير) بصلاحيات متطابقة.
الموظفون خارج النظام: يوقّعون النموذج الورقي، ويُصوَّر ويُرفع.

## التقنية
- Node.js 22.13+ (مُختبر على 24) + Express
- SQLite المدمجة في Node (`node:sqlite`) — لا حاجة لخادم قاعدة بيانات
- واجهة HTML/JS بدون build، RTL، مناسبة للجوال وسطح المكتب (قابلة للتثبيت كتطبيق PWA)
- نماذج A4 بـ HTML/CSS للطباعة أو الحفظ PDF من المتصفح

## التشغيل لأول مرة
```
npm install
copy .env.example .env      # ثم غيّر SESSION_SECRET
npm run set-user -- <اسم-المستخدم> "<كلمة-المرور>" "<الاسم>" --admin
npm start
```
ثم افتح http://localhost:3000

- `--admin` = **مدير عام**: يدير كل شيء (العهد، الاستلام والتسليم، الموظفين، الإعدادات، المستخدمين)، واسمه وتوقيعه يُطبعان في خانة «مسؤول العهدة» في كل النماذج.
- **أي مستخدم آخر = اطّلاع فقط**: يشاهد ويطبع ويصدّر بدون أي تعديل (المنع في الخادم والواجهة).
- نفس أمر `set-user` يعيد تعيين كلمة المرور إن كان المستخدم موجوداً (مفيد إذا نُسيت كلمة مرور المدير).
- الحد الأدنى لكلمة المرور 6 أحرف.

## الأقسام
- **إدارة العهد** (`#/assets`): كل قطعة سجل مستقل برقم مرجعي (AST-0001) ورقم تسلسلي لا يتكرر.
  إضافة عدة وحدات من نفس الصنف دفعة واحدة (مع دعم قارئ الباركود ولصق قائمة أرقام)، أو تصدير/استيراد Excel.
- **الاستلام والتسليم** (`#/moves`): نماذج التسليم (HO-0001) والإرجاع (RT-0001)، لكل نموذج طباعته ومرفقه الموقّع.
- **الموظفون** (`#/employees`): بيانات الموظفين (مع الجوال وزر اتصال/واتساب)، والعهد التي في ذمة كل موظف وسجل نماذجه، وتصدير/استيراد Excel.

## دورة العمل
**التسليم:** اختيار الموظف والعهد ← طباعة «نموذج تسليم عهدة» ← توقيع الموظف ← تصوير وإرفاق ← العهد في ذمة الموظف.

**الإرجاع:** اختيار الموظف ← تظهر كل عهده محددة (الأصل إرجاع كامل) ← إزالة التحديد عمّا لم يُرجَع مع ذكر السبب
← طباعة «نموذج إرجاع عهدة / إخلاء طرف» (أو «جزئي» مع جدول بالقطع غير المُرجَعة) ← توقيع ← إرفاق ← القطع المُرجَعة متاحة في المستودع.

| وضع العهدة | المعنى |
|---|---|
| متاحة في المستودع | جاهزة للتسليم |
| معلقة / بانتظار توقيع التسليم | في نموذج تسليم لم يُرفق توقيعه (محجوزة) |
| فعالة / مسلّمة | في ذمة موظف |
| طلب إرجاع / بانتظار التوقيع | في نموذج إرجاع لم يُرفق توقيعه |
| خارج الخدمة | تالفة/مستبعدة يدوياً |

النماذج قبل التوقيع يمكن تعديلها أو إلغاؤها (فتعود العهد لوضعها السابق). كل عملية تُسجَّل باسم المستخدم.

## الاستيراد من Excel
صدّر الملف من صفحة العهد (يعمل كقالب حتى لو كان فارغاً)، أضف صفوفاً بدون «الرقم المرجعي» للإضافة،
أو عدّل صفاً موجوداً للتعديل، ثم ارفعه. إن وُجد أي خطأ لا يُطبَّق شيء وتظهر الأخطاء برقم الصف.

### استيراد الموظفين
- صف بـ«رقم النظام» = تعديل ذلك الموظف.
- صف بلا «رقم النظام» لكن «الرقم الوظيفي» مسجل = تحديث صاحب الرقم (لا يتكرر) — مناسب لرفع قائمة من الموارد البشرية.
- غير ذلك = موظف جديد. الجوال يُحفظ بالأرقام فقط (تُحذف المسافات).

## الإعدادات
من شاشة الإعدادات: عنوان الشركة (تذييل النماذج)، رفع الشعار، تغيير كلمة المرور.
بيانات الترويسة الثابتة (الاسم، السجل التجاري، الرقم الضريبي) في `public/print.js`.

## البيانات والنسخ الاحتياطي
كل البيانات في مجلد `data/`:
- `custody.db` قاعدة البيانات
- `uploads/` صور النماذج الموقّعة والشعار

انسخ مجلد `data/` احتياطياً بشكل دوري.

## النشر
يحتاج خادماً يشغّل Node مع قرص دائم (لأن البيانات ملفات محلية)، مثل VPS أو Railway/Render مع Volume.
عند التشغيل خلف HTTPS اضبط `COOKIE_SECURE=1`.
